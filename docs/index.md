# duel-api

> The bot that refuses to bet — it halts when exposure exceeds the bankroll, instead of pretending an unsafe bet is runnable.

Open-source, offline-first gambling-math and protocol toolkit for inspecting betting math instead of being sold fantasies. No account needed to learn: install, run `doctor`, run `demo`.

```text
pip install --extra-index-url https://kingkillery.github.io/Duel-api/simple/ duel-api
```

- [Betting gates](betting-gates.md) — the money gates and protocol verdict rules.
- [Backtest math](backtest-math.md) — why sizing changes variance, never the sign.
- [Why this exists](why-i-built-this.md) — the honesty-first design notes.
